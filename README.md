# Health is Wealth
## Project Description

This is my project created for my module, Data-Centric Programming.

Health is Wealth is a general health tracker I've created in which I will use my personal data to uncover relationships between different factors over time and gather information on cyclic health habits. 
This project endeavours to collect and analyse my personal data, including my caloric intake, weight, time spent active (minutes), time spent sleeping (hours), and mood.

I hope that I will be able to use these patterns to make changes in my personal life for the betterment of my personal development goals.

## Questions
How does my mood affect my caloric intake?

Does my mood change based on activity level?

Is there a relationship between hours of sleep and weight?

## Data Dictionary

| Column | Data Type | Data Description
|-----------|-----------|-----------|
|Date | Date | YYYY-MM-DD |
|Time | Time | HH:MM |
|Calories | Int | Number of calories consumed in a single day |
|Weight | Float | Measured in kilograms |
|Sleep | Float | Measure in hours |
|Activity | Int | Measured in minutes|
|Mood | Int | Measured on a scale of 1 to 5, where 1 = Very bad, 3 = Neutral and 5 = Very good |
